◆ raise_error()

template<class E >
void snicholls::python::raise_error ( const E &  e)

Throws e as the C++ exception that maps to the right Python class.

A traced<X> becomes traced_exception (Python TracedError, with the location, frames and masked fields); an error that is itself a std::exception is thrown as it is (so std::out_of_range is an IndexError); anything else becomes bad_result_access<void> with snicholls::error_text(e) (Python ResultError).

Template Parameters
Ethe error type.
Parameters
ethe error.
Exceptions
asdescribed; std::bad_alloc.
