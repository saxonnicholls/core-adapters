Detailed Description

nlohmann/json hooks for snicholls::uuid: the canonical lowercase 8-4-4-4-12 string.

Overview
nlohmann::json j = id; writes "f81d4fae-7dec-11d0-a765-00a0c91e6bf6" (snicholls::to_text, lowercase). j.get<snicholls::uuid>() reads the canonical form in either case (snicholls::parse_uuid with default options); braces, urn:uuid: and the 32-digit form are refused, as is a JSON number or byte array.
const auto id = "0190A5C4-7E1B-7C3A-9F12-3B4C5D6E7F80"_uuid;
const nlohmann::json j = {{"order", id}}; // written lowercase
std::printf("%s\n", j.dump().c_str());
const auto back = j.at("order").get<snicholls::uuid>();
