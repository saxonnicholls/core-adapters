Detailed Description

The core-adapters version, and the core version it was built against.

Overview. The version of this repository, written in three places that scripts/check_version.py keeps equal: the macros below, project(... VERSION) in CMakeLists.txt and version in pyproject.toml (the Python package snicholls_core has the same number). SNICHOLLS_CORE_ADAPTERS_REQUIRE_VERSION is the compile-time check for a consumer's header, like core's SNICHOLLS_CORE_REQUIRE_VERSION.

SNICHOLLS_CORE_ADAPTERS_REQUIRE_VERSION(0, 1, 0); // fails to compile against an older core-adapters
const std::string adapters(snicholls::core_adapters::version_string());
const std::string core(snicholls::core_adapters::core_version_string());
std::printf("core-adapters %s, built against snicholls-core %s\n", adapters.c_str(), core.c_str());
